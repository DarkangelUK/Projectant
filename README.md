\# Projectant



A Windows desktop application for managing tasks, project roadmaps, and tracking time. Built with Python and CustomTkinter.



\## Prerequisites

\- Windows 10/11

\- Python 3.10+ (ensure "tcl/tk and IDLE" is checked during installation)



\## Installation \& Setup

1\. Clone the repository:

&#x20;  ```bash

&#x20;  git clone \[https://github.com/DarkangelUK/Projectant](https://github.com/DarkangelUK/Projectant)

&#x20;  cd Projectant



Install required packages:

pip install -r requirements.txt



Run the application

python Projectant.py
